# Simulador de créditos IBS & CBS — Contalger

Aplicação estática em HTML/CSS/JavaScript para simulação de receitas, débitos, créditos e saldo estimado de IBS e CBS.

## Estrutura

- `index.html` — aplicação principal
- `assets/` — logo e ícones da Contalger
- `site.webmanifest` — metadados para instalação como app
- `.nojekyll` — compatibilidade direta com GitHub Pages

## Publicar no GitHub Pages

1. Crie ou abra um repositório no GitHub.
2. Envie **todo o conteúdo desta pasta para a raiz do repositório**.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve. O GitHub mostrará a URL pública quando a publicação terminar.

## Observações

A aplicação não depende de servidor, banco de dados ou bibliotecas externas. Os dados inseridos pelo usuário permanecem no navegador por meio de armazenamento local, conforme a lógica do próprio simulador.
